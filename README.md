A deterministic Python chess engine. It plays the make.fun gauntlet with a fixed-node alpha-beta search, quiescence, and a piece-square evaluation.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
